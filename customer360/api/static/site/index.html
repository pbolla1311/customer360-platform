What's Inside

Backend architecture and data engineering patterns implemented end to end, not just named.

V1

Versioned REST API

FastAPI service exposing customer profiles at both an unversioned path and /api/v1, with a full OpenAPI 3.1 schema and self-hosted interactive docs.

DB

Customer Profile Storage

PostgreSQL via SQLAlchemy, mediated by a repository layer that centralizes bulk upserts and query logic away from route handlers.

EV

Kafka Event Processing

A producer publishes a domain event per customer profile; a companion consumer processes events idempotently by de-duplicating on event ID.

OB

Transactional Outbox

A dedicated outbox table, repository, and publisher implementing the outbox pattern with retry accounting, built and tested alongside the direct publish path.

DL

Retry & Dead-Letter Handling

Exponential backoff and dead-letter topic routing on publish failure, so a downstream outage doesn't silently drop events.

SEC

Security & Observability

Strict Content-Security-Policy, API-key auth, per-route rate limiting, structured JSON logging, and a per-request audit trail.

OPS

Docker · Kubernetes · Terraform

A container image, Kubernetes manifests, and Terraform modules for AWS infrastructure — all validated in CI on every push.

PM

Pipeline Monitor

An enterprise-monitoring-style view of the Kafka/outbox/retry/DLQ architecture — animated KPIs, a live pipeline visualization, and charts, with real and simulated data clearly labeled. See /demo/pipeline.
